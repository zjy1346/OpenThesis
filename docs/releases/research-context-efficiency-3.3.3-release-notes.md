# OpenThesis 3.3.3 Release Notes

## What's Changed

### English

This release summarizes the unpublished 3.3.1–3.3.3 work.

- **3.3.1 — Research context and request efficiency:** Added request-size and capacity diagnostics, assigned source-reading responsibilities, preserved evidence coverage, and improved scoped recovery and reuse of completed work.
- **3.3.2 — Reference and recovery reliability:** Unified nested source-reference resolution, isolated local request-compilation failures, resumed only affected work, and preserved verification state across recovery.
- **3.3.3 — Recovery and large-material planning:** Groups missing sections by shared work, persists completed results, and separates generation identity from verification changes to prevent unnecessary regeneration. Reuses frozen context and indexed observations during planning, loads original correction evidence on demand, keeps unverified claims readable without granting proof or calculation eligibility, and preserves partial financial-window progress until the complete parent window is ready.
- Improved dispatch of independent reading lanes while retaining shared provider rate limits.

### 中文

本次发布汇总此前未发布的 3.3.1–3.3.3。

- **3.3.1 — 研究上下文与请求效率：** 增加请求规模和容量诊断，明确原文阅读责任，保留证据覆盖，并改进局部恢复与已完成工作的复用。
- **3.3.2 — 引用与恢复可靠性：** 统一嵌套来源引用解析，隔离本地请求编译故障，只恢复受影响的工作，并在恢复过程中保留核验状态。
- **3.3.3 — 恢复调用与大材料规划：** 按共享任务合并缺失章节并持久化已完成结果；将生成身份与核验变化分开，避免不必要的重复生成。规划时复用冻结上下文和索引观测，按需载入原始纠错证据；未核验内容仍可阅读，但不会因此获得证明或计算资格；财报子窗口的部分进度会保留，直到父窗口完整。
- 改进独立阅读任务的调度，同时保留共享服务商限流。
