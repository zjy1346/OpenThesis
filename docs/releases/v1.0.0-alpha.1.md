# OpenThesis v1.0.0-alpha.1

## 中文

这是 OpenThesis 1.0 桌面架构的首个公开预览版。核心变化是从 Tkinter 单体界面迁移到
Tauri 2 + React/TypeScript 桌面外壳，并通过版本化 JSON-RPC 协议连接隔离的 Python
研究核心。

### 本版包含

- 报告优先的现代化研究工作台与固定导航栏。
- 可平滑展开的轻量侧栏，不再通过重排整个页面实现动画。
- 冻结的 Python sidecar、持久研究进程、进度反馈与取消操作。
- 离线合成演示研究、历史报告与结构化 HTML 财务表格。
- 独立的界面语言和报告语言设置。
- Windows x64 NSIS 安装包；用户数据写入系统应用数据目录，而不是安装目录。
- 为未来 macOS 桌面版保留的平台中立核心、路径接口和协议边界。

### Alpha 限制

真实公司 SEC 研究、模型/API Key 会话配置、研究模块、反向 DCF 控件和投资逻辑管理
尚未迁移到新界面。它们仍保留在旧版 Python 界面中。本预览版不会连接交易账户或执行
任何交易。

### 安全与隐私

- 首次启动不会调用 AI；合成演示不访问网络。
- API Key 不持久化、不写入日志或研究数据库。
- 安装包不包含开发者邮箱、研究历史、API Key、Token 或本机绝对路径。
- 发布附件包含 SHA-256 校验文件。

## English

This is the first public preview of the OpenThesis 1.0 desktop architecture.
The application moves from a monolithic Tkinter UI to a Tauri 2 +
React/TypeScript shell connected to an isolated Python research core through a
versioned JSON-RPC protocol.

### Included

- A report-first modern research workspace with a fixed navigation rail.
- A lightweight transform-based drawer that avoids whole-page layout animation.
- A frozen Python sidecar, persistent research process, progress feedback, and
  cancellation.
- Offline synthetic demo research, report history, and structured HTML financial
  tables.
- Independent interface-language and report-language settings.
- A Windows x64 NSIS installer with user data stored in the platform application
  data directory rather than the installation directory.
- Platform-neutral core, paths, and protocol boundaries for a future macOS
  desktop build.

### Alpha limitations

Real-company SEC research, model/API-key session configuration, research packs,
reverse-DCF controls, and thesis management have not yet moved to the new UI.
They remain available in the legacy Python interface. This preview has no broker
integration and cannot execute trades.

### Security and privacy

- No AI is called on first launch; the synthetic demo does not access the network.
- API keys are not persisted or written to logs or the research database.
- The installer contains no developer email, research history, API keys, tokens,
  or machine-specific absolute paths.
- A SHA-256 checksum is attached to the release.
