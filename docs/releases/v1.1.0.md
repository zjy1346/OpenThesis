# OpenThesis 1.1.0

OpenThesis 1.1.0 refines the Windows research workbench around a fixed icon rail,
hover-or-click text navigation, feature-specific page headings, a dedicated research
history page, a denser report header, and an offline bilingual help center.

The help center ships two guides: starting a real-company research run and building a
safe declarative `.othesis` research pack. Existing privacy, long-term research, and
no-trading boundaries remain unchanged.
