# OpenThesis v1.0.0-alpha.2

## 中文

这是供测试的第二个 1.0 架构预览版。

- Windows 版本改为真正的便携 ZIP：完整解压后直接运行 `OpenThesis.exe`，无需安装。
- 主程序使用 Windows GUI 子系统；Python 研究核心以隐藏控制台方式启动，不再弹出命令行窗口。
- 新增现代“发起研究”工作台：支持 SEC 公司搜索、常用公司、10-K 下载和公司事实数据。
- 新界面接入 DeepSeek、Qwen、Kimi、GLM、OpenAI、Gemini、OpenRouter、Ollama 与自定义 OpenAI-compatible 入口。
- 支持在线模型目录、会话级 API Key、第二模型对比、研究模块与反向 DCF。
- 真实公司研究现已运行完整多 Agent `ResearchWorkflow`，并继续提供进度、取消和错误反馈。
- 新增投资逻辑版本浏览与追加式编辑；历史版本不会被覆盖。
- API Key 不写入数据库、设置、报告或日志；便携包不包含个人 SEC 邮箱或研究历史。

下载 `OpenThesis-1.0.0-alpha.2-windows-x64-portable.zip`，完整解压后运行
`OpenThesis\OpenThesis.exe`。请勿单独移动 EXE；它需要同目录下的 `bin` 文件夹。

本版还加入模型连接测试、声明式 `.othesis` 研究模块导入、异常中断研究恢复，以及
报告 90%-130% 缩放、`F11`/`Esc` 专注阅读和按需技术详情。动画只使用短时合成
过渡，并尊重系统“减少动态效果”设置。

原生报告导出支持独立 HTML、Markdown 和文本，文件路径始终留在 Tauri 平台层；
同时补齐模型帮助链接与架构诊断“关于”页面。

## English

This is the second test build of the 1.0 architecture preview.

- Windows is now distributed as a true portable ZIP. Extract it completely and run `OpenThesis.exe`; no installation is required.
- The main process uses the Windows GUI subsystem, while the Python research core starts with its console hidden.
- A modern Start Research workspace now supports SEC company search, common companies, 10-K downloads, and Company Facts.
- The new interface includes DeepSeek, Qwen, Kimi, GLM, OpenAI, Gemini, OpenRouter, Ollama, and custom OpenAI-compatible entry points.
- Online model discovery, session-only API keys, second-model comparison, research packs, and reverse DCF are available.
- Real-company runs execute the full multi-agent `ResearchWorkflow` with progress, cancellation, and actionable errors.
- Investment-thesis history and append-only editing are available; previous versions are never overwritten.
- Model connection testing, declarative `.othesis` pack import, and safe recovery of research interrupted by a previous process are available.
- The report workspace supports 90%-130% zoom, `F11`/`Esc` focus reading, and opt-in technical evidence IDs with short compositor-only transitions and reduced-motion support.
- Native report export supports standalone HTML, Markdown, and text without exposing the selected filesystem path to React. Provider help links and an architecture-diagnostics About view are included.
- API keys are not written to settings, the database, reports, or logs. Portable archives contain no personal SEC contact or research history.

Download `OpenThesis-1.0.0-alpha.2-windows-x64-portable.zip`, extract it completely,
and run `OpenThesis\OpenThesis.exe`. Keep the adjacent `bin` directory with the executable.
