# OpenThesis 3.2.6 Release Notes

## What's Changed

### English

This release brings together the previously unpublished OpenThesis 3.2.0–3.2.6 updates.

- **3.2.0 — Model connections and financial concepts:** Added flexible compatible-model connections with clearer capability and usage accounting, and improved context-aware financial cost classification.
- **3.2.1 — Model Center:** Simplified connection and model management, improved proxy/network compatibility, and made request progress, cancellation, and outcomes more reliable.
- **3.2.2 — Research cost and continuity:** Improved request accounting, stable source-material reuse, focused verification, and resumable financial preparation to reduce redundant work.
- **3.2.3 — Adaptive research:** Replaced default fixed workload caps with progress-aware execution while preserving user-configured limits, safe retry behavior, and resumable PDF processing.
- **3.2.4 — PDF and research recovery:** Improved packaged PDF workers, per-source recovery, and clear recovery actions while preserving completed research when an isolated file fails.
- **3.2.5 — Financial recognition:** Strengthened source-aware financial validation and recovery, and added an optional, managed local structure-processing path.
- **3.2.6 — Faster, resumable financial parsing:** Added page-level incremental parsing and persistence, improved cache reuse and period/scope status reporting, and made recognition progress more informative.

### 中文

本次版本汇总此前尚未发布的 OpenThesis 3.2.0–3.2.6 更新。

- **3.2.0 — 模型连接与财务概念：** 增加灵活的兼容模型连接方式，改进能力与用量记录，并按上下文区分财务成本概念。
- **3.2.1 — 模型中心：** 简化连接和模型管理，增强代理与网络兼容性，并提升请求进度、取消和结果状态的可靠性。
- **3.2.2 — 研究成本与连续性：** 改进请求记账、稳定来源材料复用、针对性核验及可续作的财报准备，减少重复工作。
- **3.2.3 — 自适应研究：** 将默认固定工作量门槛改为按实际进度执行，同时保留用户设置的限制、安全重试和可续作 PDF 处理。
- **3.2.4 — PDF 与研究恢复：** 改进便携包内 PDF 工作进程、按来源恢复及恢复操作指引；单个文件故障时保留已完成的研究内容。
- **3.2.5 — 财务识别：** 加强来源约束的财务校验与恢复，并增加可选、受控的本地结构化处理路径。
- **3.2.6 — 更快且可续作的财报解析：** 增加按页增量解析与持久化，改进缓存复用和期间/口径状态呈现，让识别进度更清晰。
