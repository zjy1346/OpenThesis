# OpenThesis v1.0.0-alpha.3

## 中文

这是 Windows 优先、保持未来 macOS 可移植性的架构测试版。

- 将研究会话、报告阅读、研究配置、Thesis、设置、关于和双语目录从单体工作台迁为独立模块。
- 补回失败后重新运行、研究历史刷新和 SEC 身份帮助。
- F11/Esc 专注阅读立即响应；鼠标触发继续使用短促的合成器动画。
- 导航遮罩常驻并只过渡 `opacity`，快速反向操作不再因卸载节点闪烁。
- 递归架构契约确保所有 React 子目录都不能直接访问进程、机器路径或 Tauri 平台插件。
- 完整解压 Windows 便携 ZIP 后直接运行，无需安装。

本版本不会连接券商、执行交易或预测短期价格。API Key 仍只保留在当前会话。

## English

This is a Windows-first architecture preview that keeps the shared workbench
and research core portable to a future macOS build.

- Split research sessions, report reading, research setup, theses, settings,
  diagnostics, and localization out of the monolithic workbench shell.
- Restored retry, manual history refresh, and SEC identity guidance.
- F11/Escape focus actions are immediate; occasional pointer actions retain a
  short compositor animation.
- Kept the navigation scrim mounted and transitioned opacity only, avoiding
  flashes during rapid reversal.
- Recursive architecture contracts prevent nested React modules from directly
  accessing processes, machine paths, or native Tauri plugins.
- Extract the Windows portable ZIP completely and run it without installation.

No brokerage connectivity, order execution, or short-term price prediction is included.
API keys remain in memory for the current session only.
