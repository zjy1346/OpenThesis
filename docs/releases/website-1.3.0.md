## 2. 问题定位

### 2.1 首屏红线

- 红线来自 `hero-portal-line` 装饰元素及对应 CSS。
- 它没有表达数据、交互或空间关系，反而遮挡真实产品截图，违反 Apple Design 的 Purpose、Simplicity 与 Craft 原则。

### 2.2 证据放大区域

- 当前圆形放大镜通过固定尺寸与图片百分比位移裁切原图。
- 响应式尺寸变化后，同一位移不能稳定指向同一语义区域，导致桌面端与移动端放大位置不一致。
- 圆形窗口缺少明确标签，用户无法立即理解被强调的内容。

### 2.3 研究过程信息杂乱

- 当前视觉同时叠加完整报告截图、研究进度截图和一套人工绘制时间线。
- 三层信息竞争注意力，进度面板遮挡报告，时间线又穿过截图，空间关系不清晰。
- 随机旋转、透视和大面积覆盖削弱可预测性，不符合 Apple Design 的 Spatial consistency、Grouping 与 Simplicity 原则。

## 3. 设计决策

### 3.1 Purpose 与 Simplicity

- 完全删除首屏红线，不用另一条装饰线替代。
- 研究过程场景只保留真实报告截图与真实研究进度截图，删除重复的人工时间线。

### 3.2 Spatial consistency

- 将放大镜改为带有明确语义标签的矩形“证据来源”焦点卡。
- 焦点卡使用同一张真实截图的固定语义裁切；桌面端锚定在主截图下方边缘，移动端进入正常文档流，避免漂移。
- 研究进度使用稳定的纵向层级：报告为主、进度为辅；不再使用随机旋转和互相穿插。

### 3.3 Materials 与 Depth

- 次级焦点卡使用克制的半透明深色材质、柔和阴影和清晰边界表达层级。
- 不叠加多个浅色玻璃表面；真实截图保持清晰，浮层只承担说明和聚焦功能。

### 3.4 Motion 与 Accessibility

- 进入动画只使用 `transform` 与 `opacity`，从元素真实锚点轻微出现，不使用旋转或弹跳。
- 滚动 scrub 保持可逆、可中断；移动端不使用 pinned 叠层。
- `prefers-reduced-motion` 下保持静态、清晰、无遮挡。
