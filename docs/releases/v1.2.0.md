# OpenThesis 1.2.0 implementation notes

Version 1.2 introduces one market-data Interface backed by SEC-owned US logic,
a CNInfo adapter for SSE/SZSE/BSE, and an HKEXnews adapter for Hong Kong Main
Board and GEM disclosures.

The domain model now separates an issuer from each listed security. Legacy
`Company.cik` storage remains readable, while new records persist stable issuer
and security IDs, market, exchange, listing/reporting currencies, accounting
standard, industry, and support tier.

Official PDF normalization is deliberately conservative. Canonical annual facts
are emitted only when a recognized label and numeric value occur together. Each
fact keeps its filing URL and a page-scoped evidence excerpt. A/H quarterly
cumulative data is not converted into standalone quarters in this release.

Market prices are a manual, dated snapshot. They never masquerade as filing
facts. Reverse DCF requires the market-cap currency to match the reporting
currency, and ordinary-company FCF valuation is disabled for Financials Beta.

The Windows release remains portable: extract the ZIP and run `OpenThesis.exe`.
Local settings, SEC identity, API keys, and research history are excluded from
the archive.
